# 咕噜 Gulu

> 一款"带游戏功能的疗愈 App"，通过 MBTI 与星座精准画像，为用户生成一只真正"懂你"的专属灵魂宠物。
>
> **核心定位**：现实宠物的数字化延伸，AI 陪伴与心理健康赛道的交叉创新。

## 功能特性

### 核心系统

| 系统 | 功能 | 状态 |
|------|------|------|
| **用户画像** | MBTI 8题测试 + 4字母快捷入口 + 星座选择 + 性格分析 | ✅ 已完成 |
| **宠物生成** | AI 形象生成 + 7种视觉风格切换 + 自定义描述 | ✅ 已完成 |
| **灵魂镜像养成** | 能量场系统 + 灰化症预警与治疗 + 三段式进化 | ✅ 已完成 |
| **对话系统** | AI 对话 + 情感分析 + 行动闭环 + 安全机制 | ✅ 已完成 |
| **宠物自主系统** | 离线行为模拟 + 探险礼物 + 主动互动 | ✅ 已完成 |
| **宠物社交** | 附近发现 + 互动玩法 + 防骚扰机制 | ✅ 已完成 |
| **Citywalk** | 位置感知 + POI 打卡 + 漫步报告 | ✅ 已完成 |
| **商业化** | 商店 + 货币系统 + 背包 + 装备 | ✅ 已完成 |
| **个人中心** | 用户信息 + 宠物资料 + 设置 + 退出登录 | ✅ 已完成 |

### 关键设计决策

- **只有宠物型**一种陪伴类型（已取消恋人/朋友/导师/家人等其他类型）
- **取消毕业机制**，改为持续进化的长期陪伴关系
- 养成系统**完全免费**，仅外观/皮肤付费
- 咕噜拥有**完全自主的行为系统**，不是被动等待用户互动的工具

### 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| 客户端 | Expo (React Native) | 一套代码覆盖 iOS/Android/Web，3周可出可安装包 |
| 状态管理 | Zustand | 轻量、TypeScript友好，比Redux更适合移动端 |
| 后端框架 | Python FastAPI | 异步支持优秀，AI工程生态成熟，开发效率高 |
| 数据库 | Supabase (PostgreSQL) | 开箱即用的Auth + Realtime + Storage |
| AI对话 | DeepSeek V4 Flash | 中文理解力强，响应速度快，成本可控 |
| 图像生成 | SiliconFlow Stable Diffusion | 国内访问稳定，风格迁移效果优秀 |
| 缓存 | Redis | 对话上下文缓存，热点数据加速 |

## 快速开始

### 环境要求

- Node.js >= 18
- Python >= 3.10
- Redis (可选，用于对话上下文缓存)
- Supabase 账号 (用于数据库)

### 前端

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量 (可选，开发时使用模拟数据)
cp .env.example .env

# 3. 启动开发服务器
npx expo start --web

# 4. 类型检查
npm run type-check
```

### 后端

```bash
# 1. 进入后端目录
cd backend

# 2. 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 Supabase/Redis/DeepSeek API 密钥

# 5. 启动服务
uvicorn main:app --reload
```

### 环境变量配置

创建 `backend/.env`：

```env
# Supabase
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
SUPABASE_JWT_SECRET=your_jwt_secret

# Redis
REDIS_URL=redis://localhost:6379/0

# DeepSeek API
DEEPSEEK_API_KEY=your_deepseek_key

# SiliconFlow API (图像生成)
SILICONFLOW_API_KEY=your_siliconflow_key

# 高德地图 (Citywalk)
AMAP_API_KEY=your_amap_key
AMAP_WEB_KEY=your_amap_web_key
```

### 已修复的关键问题

- **聊天网络异常**：后端静默 Redis 连接失败，聊天接口可正常返回 AI 回复。
- **商店购买无反应**：移除 `window.confirm`/`alert`，改用 DOM Toast，购买流程已跑通。
- **探索推荐卡片无法滑动**：增加左右箭头与 `scrollTo` 控制，推荐卡片可横向切换。
- **聊天气泡不显示**：Web 端禁用原生动画驱动，气泡正常弹出。
- **UI 资产统一**：新增主界面背景、食物图标、饰品图标/佩戴图、喂食与好友按钮图标，统一由 `AssetManager` 管理。
- **属性面板统一**：探索页与首页均使用 `PetStatusBar`，体力、进化阶段与数值保持一致。

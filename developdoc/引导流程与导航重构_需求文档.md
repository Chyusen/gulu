# 咕噜 Gulu — 引导流程与导航重构需求文档

> 版本：v1.0 | 日期：2026-06-18
> 目标：将现有直白的 Onboarding 改造为互动故事式引导；将五 Tab 导航重构为宠物中心式三按钮 + 侧边可展开菜单布局；优化星座日期选择器为滚动式

---

## 一、项目背景与目标

### 1.1 背景

当前存在三个体验问题：

1. **Onboarding 过于直白**：首页直接显示"开始测试"按钮，缺乏情感连接和引导感，用户不知道自己要做什么、为什么要做
2. **导航栏繁冗**：底部五 Tab 导航（首页/对话/Citywalk/社交/我的）占据大量视觉空间，宠物不是界面中心，各功能入口扁平罗列，缺乏层次
3. **星座日期选择不友好**：通过 +/- 按钮调整月/日，操作繁琐，不符合移动端交互习惯

### 1.2 目标

1. **互动故事式引导** — 让咕噜以对话的方式一步步引导用户完成画像，建立情感连接
2. **宠物中心式导航** — 宠物固定屏幕中央，底部仅三个核心按钮，其余功能以侧边可展开菜单呈现
3. **滚动式日期选择** — 替换 +/- 按钮为原生风格的滚动选择器

### 1.3 设计原则

- **宠物即界面**：宠物是视觉中心，所有交互围绕宠物展开
- **渐进式披露**：功能入口按使用频率分层，常用直接可见，其余按需展开
- **对话即引导**：用咕噜的口吻引导用户，而非冷冰冰的表单
- **移动优先**：所有交互针对单手操作优化

## 二、Onboarding 互动故事式引导

### 2.1 引导流程总览

```
欢迎页 → 咕噜出场 → 昵称引导 → MBTI测试 → 星座选择 → 宠物生成 → 首次互动(起名)
```

### 2.2 各步骤详细设计

#### Step 1：欢迎页

**现有**：显示 App 介绍文字 + "开始我的旅程"按钮

**改造**：保留整体结构，但增加咕噜的出场动画

- 页面加载后，一个模糊的光球从屏幕底部缓缓上浮至中央
- 光球逐渐凝聚成咕噜的轮廓（使用 PetAvatar 组件 + opacity 动画）
- 咕噜出现后，文字从"开始我的旅程"变为"咕噜在等你"
- 点击按钮后，咕噜做一个开心跳跃动画，然后过渡到下一步

**动画时序**：
```
0ms    - 光球开始上浮 (translateY: 200 -> 0, duration: 800ms)
800ms  - 光球凝聚 (opacity: 0.3 -> 1, scale: 0.5 -> 1, duration: 600ms)
1400ms - 咕噜出现，文字变化
```

#### Step 2：咕噜出场 + 昵称引导

**核心交互**：咕噜主动跟用户说话，以对话气泡的形式引导用户输入昵称

- 咕噜出现在屏幕中央偏上，带呼吸动画
- 咕噜头顶飘出气泡："嗨！我是咕噜，你叫什么名字呀？"
- 屏幕底部滑入输入框（样式同沉浸式对话的 CollapsibleInput）
- 用户输入昵称后，咕噜开心跳跃 + 气泡："你好呀，{昵称}！让我来了解你吧~"
- 1.5 秒后自动过渡到 MBTI 测试

**数据流**：
- 用户输入昵称 → 调用 `useUserStore.setUser()` 保存 nickname
- 昵称不能为空，最少 1 个字符，最多 12 个字符
- 默认昵称："咕噜主人"

#### Step 3：MBTI 测试（互动式）

**现有**：标准问卷式，进度条 + 选项卡片

**改造**：以咕噜提问的方式呈现

- 每道题由咕噜"问出"，气泡显示题目文字
- 咕噜在不同题目有不同表情：
  - EI 题目：好奇表情（歪头）
  - SN 题目：思考表情（眼睛左右看）
  - TF 题目：认真表情（微微前倾）
  - JP 题目：调皮表情（左右摇晃）
- 选项以两张卡片形式呈现在咕噜下方，用户选择后咕噜做出反应
- 保留"已知我的 MBTI"快捷入口，但改为咕噜说"你已经知道自己是什么类型了吗？"→ 弹出快捷选择面板

**进度指示**：不再使用顶部进度条，改为咕噜身边的星星收集效果（每答一题，咕噜身边多一颗小星星）

#### Step 4：星座选择（含滚动式日期选择器）

**详见第五章**

#### Step 5：宠物生成

**现有**：PetCreateScreen 独立页面，选择风格 + 生成

**改造**：融入引导流程

- 咕噜说："让我变成最懂你的样子！"
- 自动根据 MBTI + 星座推荐一个风格（标记"推荐"），同时展示全部 7 种风格供选择
- 风格选择以横向滚动卡片形式呈现，咕噜在上方实时预览当前选中风格的效果
- 点击"生成咕噜"后，播放生成动画（光效 + 缩放）

#### Step 6：首次互动 + 宠物起名

- 进入主界面后，咕噜通过气泡说："我还没有名字呢，你想叫我什么？"
- 底部弹出输入框，默认文字"咕噜"
- 用户输入后，咕噜开心跳跃 + 气泡："我喜欢这个名字！{宠物名}，就是我啦~"
- 宠物名称保存到 `usePetStore`

**数据流**：
- 宠物名称 → 调用 `usePetStore` 的相关方法更新 pet.name
- 默认名称："咕噜"
- 最少 1 个字符，最多 8 个字符

### 2.3 引导流程状态管理

```typescript
// 新增 store: src/stores/onboardingStore.ts
interface OnboardingState {
  currentStep: 'welcome' | 'nickname' | 'mbti' | 'zodiac' | 'petCreate' | 'petName' | 'completed';
  userNickname: string;
  petNickname: string;
  setStep: (step: OnboardingState['currentStep']) => void;
  setUserNickname: (name: string) => void;
  setPetNickname: (name: string) => void;
  completeOnboarding: () => void;
}
```

### 2.4 引导流程与现有导航的衔接

- 引导流程使用 RootNavigator 中的新 Screen `OnboardingFlow`
- 引导完成后导航到 `Main`（新的宠物中心式主界面）
- 已完成引导的用户（user + pet 均存在）直接进入 `Main`

**行为**：

## 五、星座日期滚动选择器

### 5.1 现有问题

当前 ZodiacScreen 使用 +/- 按钮调整月/日：
- 操作繁琐，需要多次点击
- 不符合移动端日期选择的交互习惯
- 无法快速定位到目标日期

### 5.2 改造方案

替换为 **滚动式 Picker**，类似 iOS 原生日期滚轮：

```
    ┌─────────────┐  ┌─────────────┐
    │    4 月      │  │    16 日     │
    │  ▸ 5 月 ◂   │  │  ▸ 17 日 ◂  │  ← 选中行高亮
    │    6 月      │  │    18 日     │
    └─────────────┘  └─────────────┘
```

### 5.3 技术实现

**方案**：使用 `react-native-picker` 风格的自定义滚动组件

由于项目使用 Expo 且需要 Web 兼容，采用自定义实现：

```typescript
// 新增组件: src/components/ScrollPicker.tsx
interface ScrollPickerProps {
  data: string[];          // 可选项列表
  selectedIndex: number;   // 当前选中索引
  onChange: (index: number) => void;
  itemHeight: number;      // 每项高度（默认 40）
  visibleItems: number;    // 可见项数（默认 5，奇数）
}
```

**核心交互**：
- 上下滑动选择
- 选中项居中高亮，上下项渐淡
- 松手后自动吸附到最近项（snap 动画）
- 选中项有放大效果（scale: 1.1）

**月份数据**：1月 ~ 12月
**日期数据**：根据月份动态生成（1-28/29/30/31）

### 5.4 与星座计算的联动

- 滚动选择月/日后，自动调用 `calculateZodiac(month, day)` 计算星座
- 计算结果实时显示在 Picker 下方
- 无需单独的"计算星座"按钮

### 5.5 保留直接选择星座

- 滚动选择器下方仍保留 12 星座网格
- 用户可以直接点击选择星座，无需通过日期
- 两种方式选择结果同步

## 七、验收标准

### 7.1 引导流程

| 编号 | 验收项 | 通过标准 |
|------|--------|---------|
| OB-1 | 欢迎页咕噜出场 | 光球上浮 + 凝聚动画流畅，无卡顿 |
| OB-2 | 昵称输入 | 咕噜以气泡提问，输入后咕噜有开心反应 |
| OB-3 | MBTI 互动式测试 | 每题咕噜有不同表情，选项点击有反馈 |
| OB-4 | 星座滚动选择 | 上下滑动流畅，自动吸附，实时计算星座 |

# 咕噜 Gulu — 资产准备指南

> 基于 gulu-pet-demo.html 的完整资产清单
> 版本：v2.0 | 日期：2026-06-17

---

## 一、概述

本指南列出了咕噜项目开发所需的全部视觉、音频和技术资产。
咕噜是一款"带游戏功能的疗愈 App"，只有**宠物型**一种陪伴类型，
已取消毕业机制，改为持续进化的长期陪伴关系。

**资产分类：**
- 视觉资产（宠物形象、UI元素、动画素材）
- 音频资产（语音、音效、背景音乐）
- 技术资产（字体、图标、第三方资源）

**格式要求：**
- 格式：PNG（RGBA 透明通道）

**语音 TTS 实时合成规范：**
- 引擎：微软 Azure TTS / 百度语音合成
- 实时合成格式：MP3（由于语音较短，优先保证低延迟）
- 实时合成采样率：24 kHz（降低延迟和带宽）
- 实时合成比特率：96kbps（语音清晰度足够）
- 每段语音时长：< 30 秒
- 缓存策略：已合成语音缓存到本地（AsyncStorage + FileSystem）

**建议工具：** 
- TTS 引擎：微软 Azure TTS、百度语音合成
- 或 AI 声音克隆：ElevenLabs、HeyGen

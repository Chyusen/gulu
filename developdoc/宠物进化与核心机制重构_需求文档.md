## 一、项目背景与目标

### 1.1 背景

当前 Demo 已实现引导流程、主界面、宠物对话、探索页基础功能，但存在以下核心缺陷：

1. **宠物缺乏成长感**：没有进化机制，宠物状态单一，用户缺少长期留存动力。
2. **货币体系混乱**：个人中心、背包、商店的货币数量不一致，货币获取方式单一。
3. **探索功能单薄**：仅有 Citywalk 攻略，缺少散步、运动等日常活动入口，附近功能未与地图整合。
4. **引导流程不完善**：缺少性别设置、宠物性格匹配精度不足、形象选择缺少代价提示。
5. **心理疗愈机制薄弱**：缺少通过积极行为（室内/室外活动）驱动宠物成长的正向反馈闭环。

### 1.2 目标

1. **三阶段进化体系**：亲密度 + 能量 + 体力三维判定，用户主动触发进化仪式。
2. **双货币 + 任务驱动**：咕噜币（免费）/ 星尘（极低价付费），每日/每周任务阶梯式奖励。
3. **探索界面重构**：散步/运动/Citywalk/自主探索/附近五大模块，地图为底。
4. **引导流程完善**：性别必填、MBTI×星座交叉匹配、形象选择代价提示、文案优化。
5. **心理疗愈闭环**：室内外活动 → 增加能量与亲密度 → 宠物进化 → 用户成就感，形成正向循环。

### 1.3 设计原则

- **疗愈即成长**：用户的积极行为（散步、冥想、学习、社交）直接转化为宠物的能量与亲密度，让"照顾自己"与"陪伴宠物"合二为一。
- **低门槛高上限**：内向用户可通过室内活动进化宠物，外向用户可通过社交/探索加速，所有用户都有适合自己的成长路径。
- **数据单一来源**：所有页面从同一个 Store 读取货币/宠物状态，杜绝数据不一致。
- **Demo 可扩展**：3D 形象、AI 实时生成、真实社交等功能先预留接口，Demo 阶段用 Mock 数据。
- **隐私优先**：探索界面用户自主控制个人信息可见性，首次进入即可设置。

## 二、宠物进化体系

### 2.1 三大核心数值

宠物拥有三个独立数值，分别影响不同维度：

| 数值 | 说明 | 获取方式 | 消耗/衰减方式 | 上限 |
|------|------|---------|-------------|------|
| **能量** | 进化评判依据，永不衰退 | 探索、任务、室内外活动 | 无消耗 | 随进化阶段提升 |
| **体力** | 活动消耗资源 | 喂食（主要）、每日基础食物 | 探索、自主探索、社交活动 | 随进化阶段提升 |
| **亲密度** | 情感连接度 | 喂食、互动、对话、换装、陪伴活动 | 不互动时衰减 | 随进化阶段提升 |

**数值上限随进化阶段变化：**

| 进化阶段 | 体力上限 | 亲密度上限 | 能量上限 |
|---------|---------|-----------|---------|
| 萌芽体（第 1 形态） | 100 | 300 | 500 |
| 成长体（第 2 形态） | 150 | 500 | 1500 |
| 灵魂体（第 3 形态） | 200 | 800 | 3000 |

### 2.2 进化条件与仪式

**进化条件**（三个条件同时满足才能触发）：

| 目标阶段 | 亲密度阈值 | 能量阈值 | 体力要求 |
|---------|-----------|---------|---------|
| 萌芽体 → 成长体 | ≥ 200 | ≥ 500 | 当前体力 ≥ 50% |
| 成长体 → 灵魂体 | ≥ 500 | ≥ 1500 | 当前体力 ≥ 50% |

**进化仪式**：
- 条件满足时，主界面宠物上方出现"✨ 进化之光"按钮（脉冲发光动画）。
- 用户点击按钮触发进化仪式：屏幕紫光闪烁 → 宠物形态变换 → 新形态浮现 → 解锁提示。
- 进化仪式不可跳过，必须用户主动触发（仪式感是成就感的核心来源）。

**进化解锁内容**：

| 解锁类型 | 萌芽体 → 成长体 | 成长体 → 灵魂体 |
|---------|----------------|----------------|
| 互动动作 | 新增 3 种互动 | 全部互动解锁 |
| 对话风格 | 对话更丰富、更有个性 | 深度对话、灵魂共鸣 |
| 探索范围 | +50% | +100% |
| 体力/亲密度上限 | 150 / 500 | 200 / 800 |
| 自主探索时长 | 最长 4h | 最长 8h |

### 2.3 亲密度系统

**获取方式与数值**：

| 行为 | 亲密度增量 | 说明 |
|------|-----------|------|
| 喂食普通食物 | +5~10 | 按食物品质递增 |
| 喂食偏好食物 | +8~15 | 基础值 × (1.3~1.5)，随品质递增 |
| 互动（摸/戳/抱） | +3~5 | 每种每日首次 +5，后续 +3 |
| 对话 | +5~15 | 深度对话（含行动闭环）+15，普通 +5 |
| 换装 | +5 | 每件首次穿戴 +5 |
| 陪伴活动 | +10~25 | 按活动时长递增 |

**衰减规则**：

| 未互动时长 | 衰减速率 | 说明 |
|-----------|---------|------|
| 0 ~ 24 小时 | 不衰减 | 宽容期 |
| 24 ~ 72 小时 | 每天 -2% | 温和衰减 |
| 72 小时以上 | 每天 -5% | 加速衰减 |

- 衰减基于亲密度当前值的百分比，下限为 0。
- "互动"定义：任何产生亲密度增量的行为（喂食、互动、对话、换装、陪伴活动）。

### 2.4 体力系统

**恢复方式**：

| 方式 | 体力恢复 | 说明 |
|------|---------|------|
| 喂食普通食物 | +10~25 | 按食物品质递增 |
| 喂食偏好食物 | +15~35 | 基础值 × (1.3~1.5)，随品质递增 |
| 每日基础食物 | +15 | 每日限量 3 份，免费 |

**消耗方式**：

| 行为 | 体力消耗 | 说明 |
|------|---------|------|
| 散步 | -10~20 | 按时长递增 |
| 运动 | -20~40 | 按时长递增 |
| Citywalk | -15~30 | 按路线长度递增 |
| 社交互动 | -5~15 | 按互动深度递增 |
| 宠物自主探索 | -5/h（萌芽体）、-8/h（成长体）、-12/h（灵魂体） | 随时长线性消耗 |

**体力阈值**：
- 体力 < 20% 上限：无法发起探索/自主探索。
- 体力 < 10% 上限：宠物进入"疲惫"状态（动画变化：垂耳、动作迟缓、表情疲倦）。
- 体力 = 0：宠物进入"沉睡"状态，无法互动，只能通过喂食唤醒。

### 2.5 食物偏好系统

每种宠物性格类型有 3 种偏好食物。商店中食物格子的左上角显示爱心标识（❤️）表示该食物是当前宠物的偏好。

**偏好食物亲密度加成**：
- 普通品质偏好食物：亲密度 +30%
- 优良品质偏好食物：亲密度 +40%
- 稀有品质偏好食物：亲密度 +50%

**食物品质与效果**：

| 品质 | 体力恢复 | 亲密度（普通/偏好） | 价格（咕噜币） |
|------|---------|-------------------|--------------|
| 普通 | +10 | +5 / +7 | 10 |
| 优良 | +18 | +8 / +12 | 30 |
| 稀有 | +25 | +10 / +15 | 80 |

**每日基础食物**：
- 品质：普通
- 每日限量：3 份
- 价格：免费
- 效果：体力 +15，亲密度 +5

## 三、货币与任务体系

### 3.1 双货币体系

| 货币 | 获取方式 | 用途 | 是否衰退 |
|------|---------|------|---------|
| **咕噜币** | 每日任务、探索、社交、活动 | 食物、普通品质饰品/皮肤/背景 | 否 |
| **星尘** | 充值（极低价）、每周任务 | 高品质背景/皮肤/饰品、重塑宠物形象 | 否 |

**能量**不是货币，是进化资源，通过探索、任务、活动获得，永不衰退。

### 3.2 每日任务

**规则**：
- 每天生成 5 个任务，截止时间为次日凌晨 4:00，过期清零。
- 奖励为咕噜币，阶梯式：完成越多，单个任务奖励越高。
- 连续 3 天完成全部每日任务，第 4 天起奖励 ×1.5（连击加成）。
- 完成 5/5 额外奖励 50 咕噜币。

**任务示例与进化后门槛提升**：

| 任务 | 基础门槛 | 基础奖励 | 成长体门槛 | 灵魂体门槛 |
|------|---------|---------|-----------|-----------|
| 与宠物对话 | 1 次 | 20 咕噜币 | 3 次 | 5 次 |
| 喂食宠物 | 1 次 | 15 咕噜币 | 2 次 | 3 次 |
| 外出探索（散步/运动/Citywalk） | 1 次 | 30 咕噜币 | 2 次 | 3 次 |
| 完成陪伴活动 | 1 次 | 25 咕噜币 | 2 次 | 3 次 |
| 社交互动 | 1 次 | 20 咕噜币 | 2 次 | 3 次 |

**阶梯奖励**：

| 完成数量 | 单个任务奖励倍率 |
|---------|----------------|
| 1 个 | ×1.0 |
| 2 个 | ×1.0 |
| 3 个 | ×1.2 |
| 4 个 | ×1.5 |
| 5 个 | ×2.0 + 额外 50 咕噜币 |

### 3.3 每周任务

**规则**：
- 每周生成 3 个任务，周一凌晨 4:00 重置，过期清零。
- 奖励为星尘。
- 星尘奖励 = 基础星尘 × 本周每日任务完成率系数。

**完成率系数**：

| 本周每日任务完成率 | 系数 |
|------------------|------|
| 100% | ×2.0 |
| ≥ 80% | ×1.5 |
| ≥ 50% | ×1.0 |
| < 50% | ×0.5 |

**每周任务示例**：

| 任务 | 基础星尘奖励 |
|------|------------|
| 累计探索 5 次 | 10 星尘 |
| 累计与宠物对话 15 次 | 8 星尘 |
| 完成 3 次陪伴活动 | 12 星尘 |

### 3.4 货币数据源统一

- 新增 `useCurrencyStore`，所有页面（个人中心、背包、商店、任务）从该 Store 读取咕噜币和星尘余额。
- 修改货币只在 Store 层操作，UI 层纯展示。
- 禁止任何组件直接从 `userStore` 或 `petStore` 读取货币数据。

## 四、探索界面重构

### 4.1 总体布局

```
┌──────────────────────────────────────────┐
│  [← 返回]                  [⚙️ 探索设置]  │  顶部导航
│                                          │
│              🗺️ 全屏地图                  │
│         （高德 POI + 附近玩家标记）         │
│         （小红书热门笔记标记）              │
│                                          │
│                                          │
├──────────────────────────────────────────┤
│  [🚶 散步] [🏃 运动] [🧳 Citywalk]        │  活动入口
├──────────────────────────────────────────┤
│  [🐾 派遣探索]  [💌 咕噜悄悄话]            │  宠物探索
└──────────────────────────────────────────┘
```

### 4.2 地图与附近

- **地图底图**：接入高德地图 SDK，显示用户当前位置。
- **附近 POI**：调用高德 POI 搜索，在地图上标注餐厅、公园、景点等。
- **附近玩家/宠物**：在地图上显示附近用户和宠物的头像标记，点击标记弹出半屏简介卡片，展示昵称、宠物名、性别（若公开）、MBTI（若公开）、星座（若公开）、距离。
- **小红书笔记**：在地图上标注附近热门美食/旅游笔记，点击可查看笔记摘要。Demo 阶段使用 Mock 数据。
- **发布笔记按钮**：预留 UI，点击提示"✨ 该功能正在精心打磨中，敬请期待～"。

### 4.3 散步

- 调用高德 API 记录行走路线。
- 消耗体力（-10~20，按时长），增加能量（+15~30）和亲密度（+5~10）。
- 散步结束后生成"漫步报告"：路线、时长、咕噜的评语。
- 可纳入每日任务。

### 4.4 运动

- 调用高德 API 记录运动轨迹。
- 消耗体力（-20~40，按时长），增加能量（+25~50）和亲密度（+8~15）。
- 运动结束后生成"运动报告"：轨迹、时长、咕噜的鼓励。
- 可纳入每日任务。

### 4.5 Citywalk

- 保留现有功能：高德路线规划 + 攻略生成。
- 消耗体力（-15~30，按路线长度），增加能量（+20~40）和亲密度（+5~10）。
- 可纳入每日任务。

### 4.6 宠物自主探索（放置类）

- 用户设定探索时长（1h / 2h / 4h / 8h），出发前显示"预计消耗体力 XX"。
- 不同进化形态体力消耗不同：萌芽体 5/h、成长体 8/h、灵魂体 12/h。
- 体力不足则无法出发。
- 探索期间主界面宠物显示"外出中 🐾"状态（小型动画）。
- 探索结束后宠物归来，带回奖励（咕噜币、能量、随机道具）。
- 可纳入每日/每周任务。

### 4.7 咕噜悄悄话

- 宠物自主探索归来后，主界面出现"💌 咕噜悄悄话"按钮（脉冲动画提示）。
- 点击后进入对话记录页面，展示宠物在自主探索中与其他宠物的交流故事。
- **性格差异体现**：
  - 外向活泼的宠物：多条社交对话，"今天认识了新朋友小花！我们一起追蝴蝶～"
  - 内向温柔的宠物：独白式记录，"在角落发现了一朵安静的小花，它和我一样喜欢待在原地。"
- Demo 阶段使用预设故事模板，后续接入 DeepSeek 实时生成。

### 4.8 探索隐私设置

- 探索界面右上角设置按钮（⚙️），点击展开隐私设置面板。
- 设置项：
  - "向附近用户展示我的性别" — 开/关
  - "向附近用户展示我的 MBTI" — 开/关
  - "向附近用户展示我的星座" — 开/关
- 首次进入探索界面时自动弹出此面板，用户设置后不再自动弹出（后续可随时通过设置按钮修改）。
- 默认值：全部关闭（隐私优先）。

### 4.9 室内陪伴活动

室内陪伴活动是散步/运动/Citywalk 的补充，为不想外出或无法外出的用户提供宠物成长路径。所有室内活动均增加能量和亲密度。

| 活动 | 时长 | 能量增量 | 亲密度增量 | 体力消耗 | 说明 |
|------|------|---------|-----------|---------|------|
| 冥想呼吸 | 3~10 min | +5~15 | +5 | 0 | 引导式呼吸练习，宠物陪伴静心 |
| 番茄学习 | 25 min | +10 | +15 | 0 | 宠物陪伴学习，计时结束提醒休息 |
| 写日记 | 5~15 min | +5 | +10 | 0 | 宠物倾听并回应，鼓励表达 |
| 听音乐 | 10~30 min | +8 | +5 | 0 | 宠物一起"听"并轻轻摇摆 |

**番茄学习模式详细设计**：
- 25 分钟专注计时 + 5 分钟休息。
- 专注期间宠物保持"安静陪伴"姿态（闭眼、轻微呼吸）。
- 休息期间宠物"醒来"互动（伸懒腰、递水等小动画）。
- 完成一个番茄钟获得能量 +10、亲密度 +15。
- 宠物可在对话中帮用户列出 Todolist 清单（助手定位）。

## 五、引导流程完善

### 5.1 性别设置（必填）

在 WelcomeStep 昵称输入下方增加性别选择：

- 选项：男 / 女 / 不愿透露
- 必填，默认无选中
- 影响范围：宠物性格匹配权重、对话风格、推荐内容差异化、探索界面展示

**User 类型新增字段**：

```typescript
gender?: 'male' | 'female' | 'undisclosed';
```

### 5.2 MBTI × 星座交叉匹配

**当前**：MBTI → 风格 → 宠物性格（16 种线性映射）

**升级为**：MBTI × 星座 → 性格关键词 + 对话风格参数 + 食物偏好 + 活动偏好（192 种组合）

**匹配结果展示**：
- 引导流程中（宠物降生后）展示匹配理由，如：
  > "你是 INFP 型双鱼座——温柔的理想主义者与梦幻灵魂的交汇，你的咕噜将是一位细腻的梦境编织者。"
- 个人中心展示宠物性格标签和匹配理由。

**后续扩展**：根据用户行为数据（互动偏好、活动选择、对话关键词）动态微调匹配结果。

### 5.3 宠物形象选择提醒

在 PetCreateStep（基因注入）选择形象时，增加提示文案：

> "🌟 每只咕噜都是独一无二的灵魂伙伴。选定形象后，若想重塑需要消耗星尘，且进化形态将回到第一形态重新培养哦～请慎重选择～"

### 5.4 MBTI 快捷入口文案优化

**当前文案**：
> "已经知道自己的 MBTI 类型？（选填）"

**优化为**：
> "✨ 如果已经知道自己的 MBTI，可以直接告诉咕噜，跳过测试更快降生～"

### 5.5 引导断点续传

- `onboardingStore` 已持久化当前步骤，APP 重启后从断点继续。
- 老用户换新设备：若引导流程未完成，云端同步后仍需重新进入引导流程（从断点步骤继续）。
- 老用户引导已完成：云端同步后直接进入主界面，无需引导。
- 不需要"跳过引导"选项（引导流程已有 MBTI/星座快捷入口）。

### 5.6 引导完成后修改信息

- 用户可在设置中重新修改 MBTI 和星座。
- 宠物形象修改需通过"重塑"机制（见 5.7）。

### 5.7 宠物重塑机制

- 消耗星尘重塑宠物形象。
- 保留性格，形象根据用户意愿重新 AI 生成。
- 进化形态回到第一形态（萌芽体），亲密度和能量保留但上限重置。
- 重塑前二次确认弹窗：
  > "重塑后，咕噜将回到萌芽体重新成长，当前进化进度会重置。确定要重塑吗？"

## 七、心理疗愈无感推断

### 7.1 设计理念

不做传统心理量表（用户抗拒），采用**行为信号推断模型**，APP 后台持续采集行为信号，构建用户心理状态画像，个性化调整互动策略。

### 7.2 信号维度

| 信号维度 | 数据来源 | 推断方向 |
|---------|---------|---------|
| 互动频率 | 每日对话/互动次数 | 活跃度 |
| 对话语调 | 对话关键词情感分析 | 情绪倾向 |
| 活动选择 | 倾向独处/社交/运动 | 社交意愿 |
| 作息规律 | APP 使用时间段 | 生活规律性 |
| 亲密度趋势 | 亲密度变化曲线 | 关系投入度 |

### 7.3 互动策略调整

| 推断结果 | 互动策略 |
|---------|---------|
| 情绪低落 | 宠物主动关怀、推荐冥想/音乐活动、对话语气更温柔 |
| 社交回避 | 推荐室内陪伴活动、减少社交推荐、宠物更依赖用户 |
| 生活不规律 | 温和提醒作息、推荐番茄学习、宠物"担心"表现 |
| 互动活跃 | 推荐探索/社交活动、对话更活泼、增加挑战性任务 |

### 7.4 展示方式

- **不对用户展示"心理评估"字样**。
- 以"咕噜更懂你了"的方式呈现，如："咕噜发现你今天好像有点累，要不要一起听会儿音乐？"

## 八、3D 形象规划（Demo 阶段策略）

### 8.1 Demo 阶段决策

**机制优先，3D 概念验证延后**。当前 Demo 保持 2D 贴图，优先完善核心机制。

### 8.2 后续规划

| 阶段 | 策略 |
|------|------|
| 当前 Demo | 2D 贴图 + 程序化动画（呼吸、眨眼、弹跳） |
| 概念验证 | `expo-gl` + `three.js` 做 1 只宠物的 3D 展示 |
| 正式版 | 根据目标平台决定：移动端 3D，手表/眼镜端 2D 简化版 |

### 8.3 多端适配

```
移动端（手机）  → 3D 模型 + 完整动画
手表端         → 2D 简化贴图 + 基础动画
AI 眼镜端     → 2D 极简贴图 / 纯语音交互
```

数据层统一（宠物状态、性格、亲密度跨端同步），仅渲染层不同。

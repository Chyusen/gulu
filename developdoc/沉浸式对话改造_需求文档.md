# 咕噜 Gulu — 沉浸式对话界面改造需求文档

> 版本：v1.0 | 日期：2026-06-17
> 目标：将现有传统聊天界面改造为 Replika 风格的全屏沉浸式对话体验

---

## 一、项目背景与目标

### 1.1 背景

当前 ChatScreen 采用传统微信式聊天布局：
- 消息列表上下滚动
- 用户右气泡 / 宠物左气泡
- 底部固定输入框
- 宠物形象完全缺席

### 1.2 目标

1. 全屏沉浸式体验 —— 用户打开对话页时，首先看到的是一只活灵活现的宠物
2. 宠物即界面 —— 宠物是视觉中心，所有交互围绕宠物展开
3. 轻量级对话 —— 对话气泡轻盈飘出，不占据主体视觉空间
4. 直觉化互动 —— 点击宠物即可互动，无需寻找按钮

### 1.3 设计原则

- 宠物优先：宠物形象占据屏幕 50% 以上空间
- 对话轻盈：气泡自动飘出、自动消失
- 互动自然：抚摸、戳一戳等动作符合直觉
- 历史可溯：完整历史记录仍可查看

---

## 二、整体布局方案

### 2.1 屏幕分区

```
顶部状态栏
浮动气泡区（上 40%）—— 新消息从宠物头部飘出，最多3条
宠物展示区（中 35%）—— 宠物居中偏下，支持动画，点击/长按交互
底部操作区（下 25%）—— [历史] [对话] [设置] + 可收起输入框
```

### 2.2 默认状态 vs 对话展开状态

| 状态 | 宠物展示区 | 底部区域 | 气泡行为 |
|------|-----------|---------|---------|
| 默认 | 最大化（占屏幕 60%） | 仅显示圆形"对话"按钮 + 快捷操作栏 | 气泡自动飘出并消失 |
| 对话展开 | 缩小至 40% | 输入框从底部滑入 | 气泡暂停消失 |

## 三、宠物动画系统

### 3.1 呼吸循环动画

```typescript
const BREATH_CONFIG = {
  scaleMin: 1.0,
  scaleMax: 1.03,
  duration: 3000,
};
```

- 常态：持续循环呼吸，宠物微微起伏
- 灰化状态：呼吸频率降低（duration: 5000），幅度减小（scaleMax: 1.01）
- 休眠状态：呼吸几乎停止（duration: 8000），透明度降至 0.6
- 开心状态：呼吸加快（duration: 1500），幅度增大（scaleMax: 1.05）

### 3.2 眨眼动画

```typescript
const BLINK_CONFIG = {
  intervalMin: 2000,
  intervalMax: 6000,
  duration: 150,
  probability: 0.7,
};
```

- 使用 scaleY 从 1 -> 0.1 -> 1 模拟闭眼
- 眨眼时暂停呼吸动画

### 3.3 表情变化动画

| 情绪状态 | 动画表现 | 技术实现 |
|---------|---------|---------|
| normal | 正常呼吸 + 偶尔眨眼 | Animated.loop(scale) |
| happy | 快速弹跳 + 眼睛弯成月牙 | spring(scale: 1.1) + rotateZ |
| sad | 低头 + 缓慢呼吸 + 偶尔颤抖 | translateY(10) + rotateZ(5) |
| graying | 呼吸减缓 + 身体微缩 + 灰度滤镜 | duration增加 + scale(0.95) |
| dormant | 几乎静止 + 半透明 | opacity(0.5) + scale(0.9) |
| excited | 左右摇晃 + 快速呼吸 | translateX(-5~5) + 快速scale循环 |
| anxious | 微微颤抖 + 频繁眨眼 | 随机小幅度translate + 高频眨眼 |

### 3.4 动画优先级

优先级（高->低）：
1. 互动触发动画（抚摸/戳一戳/拥抱）—— 中断其他动画
2. 情绪状态动画 —— 持续播放，可被互动动画中断
3. 呼吸循环 —— 基础动画，最低优先级
4. 眨眼 —— 穿插在其他动画间隙

## 四、浮动气泡系统

### 4.1 气泡行为规则

```typescript
const BUBBLE_CONFIG = {
  maxVisible: 3,
  displayDuration: 6000,
  fadeOutDuration: 1000,
  spawnOffsetY: -120,
  driftDistance: 30,
  maxWidth: 280,
};
```

### 4.2 气泡生命周期

1. 消息到达 -> 从宠物头部位置生成气泡
2. 入场动画 -> scale(0->1) + opacity(0->1)，300ms，spring 缓动
3. 停留阶段 -> 保持显示 6 秒
4. 漂移阶段 -> 缓慢向上漂移 30 像素
5. 淡出阶段 -> opacity(1->0)，1 秒
6. 销毁 -> 从渲染列表移除

### 4.3 多气泡堆叠

- 第 1 条气泡：基准位置（宠物头部上方）
- 第 2 条气泡：向上偏移 60px
- 第 3 条气泡：向上偏移 120px
- 第 4 条到达时：第 1 条立即加速淡出

### 4.4 历史记录查看

- 点击底部「历史」按钮 -> 从底部滑出全屏面板
- 面板内展示完整消息列表
- 面板可下拉关闭

### 4.5 用户发送消息时的反馈

- 用户点击发送后：输入框收起，宠物立即播放"倾听"动画（微微前倾）
- AI 回复到达时：宠物播放"说话"动画（嘴巴微张 + 气泡飘出）
- 打字状态：宠物播放"思考"动画（歪头 + 眼睛左右看）

## 五、宠物互动系统

### 5.1 交互手势

| 手势 | 触发条件 | 响应动作 |
|------|---------|---------|
| 短按（< 500ms） | 点击宠物区域 | 随机即时反馈 + 弹出短气泡 |
| 长按（> 500ms） | 按住宠物不放 | 展开圆形互动菜单 |
| 双击 | 快速点击两次 | 特殊互动（"惊喜"反应） |

### 5.2 短按即时反馈池

| 反馈类型 | 动画 | 音效 | 气泡文案示例 |
|---------|------|------|------------|
| 抚摸 | 眯眼 + 微微后仰 | sfx_pet.wav | "好舒服~" / "你的手指好温暖" |
| 关注 | 抬头看你 | sfx_click.wav | "嗯？我在听呢" / "你找我呀？" |
| 开心 | 小幅度跳跃 | sfx_feed.wav | "见到你好开心！" |
| 撒娇 | 身体微蹭 | sfx_pet.wav | "再摸一下嘛~" |

触发概率：
- 开心状态：80%概率触发正面反馈
- 灰化状态：50%概率触发治疗引导反馈
- 休眠状态：30%概率唤醒，70%无反应

### 5.3 长按圆形互动菜单

```
       拥抱
   抚摸    戳一戳
       喂食
（菜单围绕宠物呈放射状展开）
```

- 宠物微缩至 0.8 倍
- 4 个菜单项从宠物中心呈放射状弹出
- 点击菜单项后，菜单收回，播放对应互动动画

### 5.4 互动动作详情

#### 抚摸
- 动画：眯眼 + 后仰 + 嘴巴开合
- 时长：1.5 秒
- 能量影响：+2 能量
- 气泡："好舒服~" / "你的手好温暖" / "再摸一下嘛~"
- 音效：sfx_pet.wav

#### 戳一戳
- 动画：被戳后抖动 + 歪头疑惑
- 时长：1 秒
- 气泡："哎呀！" / "戳我干嘛呀？" / "调皮~"
- 音效：sfx_click.wav

#### 拥抱
- 动画：跳进怀里（放大 + 上移）+ 爱心粒子效果
- 时长：2 秒
- 能量影响：+5 能量
- 气泡："抱抱！" / "我好喜欢你~" / "这样好安心"
- 音效：sfx_heal.wav

#### 喂食
- 动画：张嘴吃东西 + 咀嚼 + 开心跳跃
- 时长：2.5 秒
- 能量影响：根据食物类型
- 气泡："好吃！" / "谢谢你！" / "这是我最喜欢的！"
- 音效：sfx_feed.wav

### 5.5 互动冷却时间

- 同一互动动作间隔至少 3 秒
- 连续短按 3 次后，宠物进入"疲惫"状态（5 秒内不响应短按）
- 冷却期间点击宠物，显示："让我歇一下嘛~"

## 六、输入框设计

### 6.1 收起状态（默认）

- 底部仅显示快捷操作栏（历史 / 对话 / 设置）
- 「对话」按钮为圆形，带麦克风图标
- 点击「对话」按钮 -> 展开输入框

### 6.2 展开状态

- 输入框从底部滑入（translateY: 100% -> 0，300ms）
- 宠物展示区同时缩小（scale: 1 -> 0.7，translateY: 0 -> -50）
- 发送消息后，输入框自动收起，宠物恢复默认大小
- 点击空白区域也可收起输入框

### 6.3 语音输入模式

- 长按「对话」按钮 -> 进入语音输入模式
- 显示波形动画（宠物旁边出现声音波形）
- 松开后发送语音转文字消息
- 宠物播放"倾听"动画

## 八、验收标准

| 编号 | 验收项 | 通过标准 |
|------|--------|---------|
| AC-1 | 宠物呼吸动画 | 持续微弱缩放循环，肉眼可感知但不突兀 |
| AC-2 | 宠物眨眼动画 | 2-6秒随机间隔眨眼，眨眼期间呼吸暂停 |
| AC-3 | 情绪状态切换 | 切换情绪时，动画在300ms内平滑过渡 |
| AC-4 | 浮动气泡 | 新消息从宠物头部飘出，停留6秒后淡出 |
| AC-5 | 气泡入场 | 以 spring 动画弹出，不是生硬出现 |
| AC-6 | 历史记录 | 点击「历史」可查看完整记录，下拉关闭 |
| AC-7 | 短按反馈 | 短按触发随机反馈（动画+音效+气泡），3秒冷却 |
| AC-8 | 长按菜单 | 长按500ms后展开圆形菜单，选择后播放互动 |
| AC-9 | 输入框收起 | 默认隐藏，发送后自动收起 |
| AC-10 | 灰化状态 | 灰化时呼吸减缓、颜色变灰、反应冷淡 |
| AC-11 | 首屏加载 | 从点击Tab到宠物出现 < 500ms |
| AC-12 | 动画帧率 | 所有动画保持 60fps |
